# Fontes OFL compartilhadas

Oito famílias, todas SIL Open Font License 1.1 (livre inclusive para uso
comercial). Usadas em cartelas, overlays e no kit `tools/motion/` (o `prepare`
do `package.json` copia estas fontes para `tools/motion/public/fonts`).

| Família | Fonte/origem | Licença |
|---|---|---|
| Inter | Google Fonts | OFL 1.1 |
| Space Mono | Google Fonts | OFL 1.1 |
| Cormorant | Google Fonts | OFL 1.1 |
| EB Garamond | Google Fonts | OFL 1.1 |
| Playfair Display | Google Fonts | OFL 1.1 |
| Fredericka the Great | Google Fonts | OFL 1.1 |
| Manrope | Google Fonts (`ofl/manrope`) | OFL 1.1 (`OFL-Manrope.txt`) |
| DM Mono | Google Fonts (`ofl/dmmono`) | OFL 1.1 (`OFL-DMMono.txt`) |

A OFL exige que o texto da licença viaje junto com a fonte em qualquer
redistribuição - por isso os `.ttf` ficam versionados aqui em vez de baixados
sob demanda; qualquer cópia (ex.: `tools/motion/public/fonts`) precisa manter
essa proveniência.
